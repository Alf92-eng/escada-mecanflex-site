# Calculadora Mecanflex — Orguel

Interface pública da calculadora, hospedada no GitHub Pages.

[Abrir a calculadora](https://alf92-eng.github.io/escada-mecanflex-site/)

Os arquivos deste repositório contêm apenas a interface e a marca. O cálculo é executado pela API do servidor; somente o peso total é recebido pelo navegador.

Para publicar, configure GitHub Pages para a branch `main`, pasta raiz.
